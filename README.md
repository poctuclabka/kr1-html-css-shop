# Зоомагазин «Лапки и Хвосты»

Учебный многостраничный сайт зоомагазина. Выполнен на **HTML, CSS и
JavaScript** с локальным подключением **Bootstrap 5**, без React и без сборки.

Структура повторяет КР №2: отдельные HTML-страницы, общий `css/custom.css`,
скрипты `theme.js`, `main.js`, `recent.js`, локальный Bootstrap в `vendor/`
и папка `images/`. Дополнительно добавлена корзина — `cart.html` и `js/cart.js`.

## О проекте

«Лапки и Хвосты» — магазин товаров для кошек, собак, грызунов, птиц и рыб.
В проекте есть каталог с фильтрами, корзина, калькулятор доставки, оформление
заказа, отзывы на товары, статьи, сбор корма для приюта и подарочные сертификаты.

## Технологии

- **HTML5** — семантическая разметка, формы, таблицы;
- **CSS3** — переменные, Flexbox, CSS Grid, адаптивная вёрстка;
- **JavaScript** — фильтры, корзина, отзывы, темы, уведомления, `localStorage`;
- **Bootstrap 5.3.8** — подключён локально из `vendor/`, без CDN;
- **Inter** — шрифт Google Fonts;
- **Git / GitHub Pages** — публикация статического сайта.

## Возможности

1. **Bootstrap локально** — файлы лежат в `vendor/bootstrap/`, CDN не нужен.
2. **Светлая и тёмная тема** — CSS-переменные, `data-theme`, сохранение в
   `localStorage`; тема применяется до отрисовки страницы.
3. **Всплывающие уведомления** — Bootstrap Toast при добавлении в корзину,
   отправке отзыва, заказе и ошибках валидации.
4. **«Недавно просмотренные»** — каталог запоминает до четырёх открытых
   товаров и показывает их под сеткой.
5. **Sticky-фильтры** — фильтры каталога держатся под шапкой; высота шапки
   измеряется в `main.js` и передаётся в CSS-переменную.
6. **Корзина** — отдельная страница, кнопка со счётчиком в шапке,
   изменение количества, удаление и очистка, сохранение в `localStorage`.
7. **Калькулятор доставки** — город, способ получения, бесплатная доставка
   от суммы; пересчёт итога в корзине и при оформлении.
8. **Отзывы на товары** — звёзды, средняя оценка, форма с валидацией;
   отзывы сохраняются в браузере.
9. **Сбор корма для приюта** — прогресс-бар, быстрые суммы и своя сумма;
   прогресс сохраняется в `localStorage`.
10. **Карусель подборок** и **аккордеон FAQ** — компоненты Bootstrap.
11. **Быстрый заказ** — модальное окно на странице товара.
12. **Кнопка «Наверх»**, фон с лапками и курсор-лапка.
13. **Адаптивность** — мобильное меню, одна колонка карточек, проверено
    на ширине 390 px без горизонтального скролла.

## Запуск

Сборка не требуется. Откройте папку проекта через локальный сервер:

```bash
python -m http.server 8000
```

Затем перейдите на http://localhost:8000/.

Запускать через сервер лучше потому, что корзина, тема и просмотры хранятся
в `localStorage` и должны быть общими для всех страниц. На GitHub Pages это
работает автоматически.

## Замена изображений

Фотографии товаров и питомцев лежат в папке `images/`. Замените файл,
сохранив имя и путь. Рекомендуемый формат — JPG, допустимы WebP и AVIF:

| Файлы | Где используется |
|---|---|
| `images/cat-food.jpg`, `dog-food.jpg`, `cat-bed.jpg`, `cat-toy.avif`, `dog-set.webp`, `dog-bed.jpg`, `bird-food.jpg`, `bird-house.jpg`, `fish-food.jpg`, `fish-aquarium.webp`, `mouse-food.jpeg`, `mouse-wheel.jpg` | 12 карточек товаров и их страницы |
| `images/cat-hero.jpg` | hero на главной |
| `images/cat-eats.jpg`, `images/doggy.jpg`, `images/birdathome.jpg` | обложки статей |
| `images/cat.jpeg`, `images/dog.jpg`, `images/birds.jpg` | слайды карусели |
| `images/placeholder-product.jpg`, `images/placeholder-article.jpg` | запасные изображения |

Пути к фотографиям указаны прямо в карточках каталога и на страницах
товаров. Если меняете имя или расширение файла, поправьте путь в HTML
и в атрибуте `data-image` кнопки «В корзину».

## Данные в браузере

| Ключ `localStorage` | Что хранит |
|---|---|
| `lhp-theme` | `light` / `dark` |
| `lhp-cart-v2` | товары, количество, цена и фото |
| `lhp-delivery-v1` | город и способ получения |
| `lhp-recent-v2` | до 4 просмотренных товаров |
| `lhp-reviews-<slug>` | отзывы пользователя по товару |
| `lhp-charity-donated` | сумма помощи приюту |

## Валидация

Формы используют HTML5-ограничения (`required`, `minlength`, `pattern`,
`type="email"`, `type="tel"`), проверку `form.checkValidity()` и класс
`was-validated`. При ошибке показывается красное уведомление, при успехе —
зелёное. Телефон проверяется по формату `+7 (999) 346-78-91`.

## Публикация

Сайт статический, поэтому на GitHub Pages достаточно включить
**Settings → Pages → Deploy from a branch → main / (root)**.
Сборка и GitHub Actions не нужны.
